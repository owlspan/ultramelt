# UltraMelt

The update service for **UltraMelt** and **UltraMelt 2**.

Every copy of the games checks here when it starts. When there's a new
version, a button on the title screen downloads it, installs it and restarts
the game.

The files here are **scrambled**: only a copy of the game can open them, so
there's nothing to play from this page. To get the games, ask the developer.
